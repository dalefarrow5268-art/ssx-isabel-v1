# SSX Isabel V1

Isabel is the visible assistant experience for SSX's Scout Engine. This starter uses the handoff package as its baseline and frames the first screen as Isabel's SSX office/control center instead of a conventional dashboard.

## Current Direction

- The screen is Isabel's office, not a chat window.
- Isabel moves between physical stations: evidence wall, weather board, writing desk, authority table, memory vault, and audit board.
- Weather is treated as an operations risk board: a watch item, not a confirmed delay.
- External actions stay blocked until human confirmation.

## Local Development

```bash
npm install
npm run dev
```

The original handoff notes and screenshot are saved under `docs/`.
