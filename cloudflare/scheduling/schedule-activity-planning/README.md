# SSX Schedule Activity Planning Library

**Purpose:** Central, easy-access source for potential activities that may need to be added to a construction project schedule.

## Category folders

1. [Inspections](./inspections/MASTER_INSPECTIONS.md) — AHJ, special, trade, environmental, safety, final, Fire Marshal, TCO and CO inspections.
2. [Testing](./testing/MASTER_TESTING_REQUIREMENTS.md) — Field, laboratory, pressure, performance, acceptance and commissioning tests.
3. [Deliveries](./deliveries/MASTER_DELIVERIES.md) — Material, equipment, owner-furnished, prefabricated, long-lead and closeout deliveries.
4. [Safety](./safety/MASTER_SAFETY_ACTIVITIES.md) — Safety inspections, toolbox talks, permits, audits, drills and compliance checks.
5. [Training](./training/MASTER_TRAINING_REQUIREMENTS.md) — Orientations, operator training, competent/qualified-person roles, certifications and refreshers.

## SSX activity types

- Inspection
- Testing
- Delivery
- Safety Inspection
- Safety Meeting
- Safety Permit
- Safety Training
- Emergency Drill
- Commissioning
- Closeout

## Common scheduling fields

- Activity name and category
- CSI division/trade
- Responsible company and person
- Governing requirement
- Predecessors and successors
- Required notice period
- Planned and actual dates
- Frequency or recurrence
- Hold point / work blocked
- Required inspector, tester, trainer, witness or operator
- Status, result and corrective action
- Report, certificate or attachment
- Expiration or renewal date
- Project applicability

> These are master-universe lists. Each project schedule should use only the activities applicable to its plans, specifications, permits, jurisdiction, owner requirements and site conditions.
