## Employment cycle

`Standby → Assigned → Working → Completed → Standby`

Employees may pause at `Waiting for Input`, `Waiting for Approval`, `Exception` or `Held`. A new project upload creates assignments automatically. No employee runs continuously while there is no project work.

See `EMPLOYEE_CARE_STANDARD.md` for the company’s care and accountability commitments and `employee-roster.json` for the machine-readable roster used by the fulfillment system.
