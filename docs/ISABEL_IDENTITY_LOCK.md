# Isabel identity lock

The approved Isabel face and appearance references are the only visual authority for character work.

Rules:
- Never substitute a generic office woman.
- Keep Isabel separate from the office scene.
- Drive motion, gaze, speech and presence in code.
- Treat the approved headshot as the face lock and the approved multi-view board as the body, clothing and expression lock.
- Generated concept images are not runtime animation assets.

Current milestone: an identity-locked 2.5D motion harness that proves the approved face can remain stable while code controls breathing, blinking, attention, speaking state and presentation state. This harness will later be replaced by the production facial and skeletal rig without changing the Presence Director contract.
